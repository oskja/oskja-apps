Wanted To Say / イエルメモ

Data Transfer Guide / データ移行ガイド

Last updated: May 2026

Overview / 概要

Wanted To Say stores your language memos and study records locally on your device.

Wanted To Say はメモや学習記録を端末内に保存します。

Export Data / データを書き出す

Open Settings and select Export Data.

設定画面から「データをエクスポート」を選択してください。

A backup file such as wanted-to-say-backup-2026-05-29.json will be created.

以下のようなバックアップファイルが作成されます。

Transfer File / ファイルを移動する

Move the exported JSON file to your new device.

作成された JSON ファイルを新しい端末へ移動してください。

Import Data / データを読み込む

Open Settings and select Import Data.

設定画面から「データをインポート」を選択してください。

Select the exported backup file.

書き出したバックアップファイルを選択してください。

Notes / 注意事項

Imported data may replace existing records.

インポート時に既存データが上書きされる場合があります。

Regular backups are recommended.

定期的なバックアップをおすすめします。
